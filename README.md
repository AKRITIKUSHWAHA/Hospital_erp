🏥 Advanced Clinic Management System (CMS)A professional, real-time healthcare management platform designed to streamline doctor-patient interactions, financial tracking, and clinical operations. This system features a robust Admin Dashboard with real-time communication capabilities.🚀 Core Features📊 1. Intelligent Admin DashboardLive Analytics: Real-time tracking of Total Doctors, Daily Appointments, and Patient Traffic.Financial Oversight: Automated calculation of Online vs. Offline (Pay at Clinic) revenue.Doctor Management: Full CRUD operations to Register, Monitor, or Remove medical staff.Transaction Tracking: Dedicated logs for UTR (Unique Transaction Reference) Numbers to verify online payments.💬 2. Real-time Communication SuiteSocket.io Integration: Instant, zero-latency messaging between Admin and Patients.Multi-Patient Chat Sidebar: A dynamic list within the chat window to switch between different patient conversations seamlessly.Notification System: Visual "Unread" indicators (Green Dots) and browser-level toast notifications for incoming messages.Message History: Automatic fetching of past conversations from the database.📅 3. Precision SchedulingIST Synchronization: Entire system operates on Indian Standard Time (Asia/Kolkata) for accurate appointment scheduling.Advanced Filtering: Filter logs by Date, Patient Name, or Doctor to find specific records in seconds.Status Management: Update and track appointment statuses (Confirmed/Pending/Rejected).🎨 4. Modern User InterfaceAdaptive Theme: One-click toggle between Light Mode and Dark Mode.Responsive Design: Optimized for both desktop and tablet views.Data Scannability: Clean tables with status badges and highlighted payment IDs.🛠️ Technical StackLayerTechnologyFrontendReact.js (Hooks, Context API)BackendNode.js & Express.jsReal-timeSocket.ioDatabaseMySQL / PostgreSQLAPI ClientAxiosStylingDynamic CSS-in-JS & React-Toastify📂 System ArchitectureAdminDashboard.js: The central engine handling stats, doctor registration, appointment logs, and the floating chat system.Layout.js: Provides the structural UI wrapper and navigation consistency.Socket Connection: Established at the top level to ensure the Admin never misses a message regardless of the current task.⚙️ Setup & InstallationClone the RepositoryBashgit clone [repository-url]

🛡️ Security & AuthenticationRole-Based Access Control (RBAC): Strict redirection logic ensures only users with the admin role can access the dashboard.Session Management: Implements a 12-hour auto-logout mechanism based on login timestamps to prevent unauthorized access on shared terminals.Data Integrity: Validates UTR numbers and mobile credentials during registration.
